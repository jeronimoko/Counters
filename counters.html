Windows Setup
1
Start the server
In File Explorer, click the address bar of the folder containing counters.html, type cmd, press Enter. Then run:
python -m http.server 8080
2
Find your Wi-Fi IP address
Open a second Command Prompt and run:
ipconfig
Look for IPv4 Address under your Wi-Fi adapter.
It looks like 192.168.x.x
3
Open this on your iPhone
Make sure iPhone is on the same Wi-Fi. Open Safari and type:
http://192.168.x.x:8080/counters.html
Replace 192.168.x.x with your actual IP from step 2.
4
Add to Home Screen
In Safari tap Share ↑ → Add to Home Screen. Done — you never need the server again.

Data Backup
Export
Downloads a counters_backup.json file containing all your counters, values, and full history. Save it somewhere safe before updating the app.
Import
Restore counters from a previously exported backup file. This replaces all current data.
Your data is stored in this browser's local storage, tied to the URL you access the app from. As long as you keep using the same IP address and port (e.g. http://192.168.1.42:8080), updates won't affect your data — just replace the HTML file and refresh. If the URL ever changes, export first.
